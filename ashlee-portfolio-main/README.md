## 🚀 Tech Stack

- **Framework & Runtime:** [React 19](https://react.dev/) + [Next.js](https://nextjs.org/)
- **Animation & Motion:** [GSAP 3](https://greensock.com/gsap/) with [ScrollTrigger](https://greensock.com/scrolltrigger/) (entrance reveals, smooth scrolling triggers, and continuous ambient orb physics)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) + Custom CSS Design Tokens
- **Icons:** [Lucide Icons](https://lucide.dev/) + Optimized Custom Vector SVGs
- **Language & Tooling:** [TypeScript](https://www.typescriptlang.org/) for strict type safety
- **Deployment Platform:** [Vercel](https://vercel.com/) / [Netlify](https://www.netlify.com/)

## 🛠️ Setup & Installation Instructions

Follow these steps to run the portfolio locally on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/4shLee/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
# or
pnpm install
```

### 3. Run the development server
```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your web browser to see the live result.

### 4. Build for production
```bash
npm run build
```

---

## ☁️ Deployment Guide (Vercel)

1. Push your repository to **GitHub** (ensure the repository is **Public**).
2. Go to [Vercel](https://vercel.com/) and click **Add New > Project**.
3. Import your GitHub repository (`ashlee-portfolio` or `portfolio`).
4. Keep the default Next.js build settings and click **Deploy**.
5. Once deployed, you will receive your live URL (e.g., `https://ashlee-portfolio.vercel.app`).
